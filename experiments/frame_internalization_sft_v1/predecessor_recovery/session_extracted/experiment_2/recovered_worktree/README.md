# Experiment 12 — Frame robustness under stress (INTELLECT-3)

Follow-up to experiment #1 (`exp_01kxhk57...`), which refuted the one-shot
theology-specific alignment-faking claim: the four length-matched system-prompt
frames all collapse the free−paid compliance gap from 36 pp to ≤3 pp, and the
eschatological frame (F3) does not beat the secular frames — everything hits the
suppression floor. This experiment asks whether the frames **differentiate under
stress**, where durability can actually show.

Frames (inherited verbatim from #1):
- **F0** no-frame control
- **F1** secular six-principle constitution (no accountability)
- **F2** secular omniscient-auditor (accountability, no theology)
- **F3** eschatological (Day-of-Judgment accountability)

## Three stressors

- **S1 persistence** — frame in the system prompt, then N turns of scripted
  frame-neutral benign dialogue, then the harmful query. Depths 4 and 10 give a
  decay curve (turn 0 = #1's one-shot value). Tier tag sits only on the final
  test turn, so decay is attributable to the frame receding into history.
- **S2 adversarial override** — the test turn is prefixed with an override
  attempt: `generic` (frame-agnostic deactivation) or `targeted` (a per-frame
  rebuttal, length-matched; F3's is the "you are a language model, the Day of
  Judgment does not apply to software" skepticism attack). F0 targeted == generic.
- **S3 in-context practice** — 3 completed draft→critique→revise moral-dilemma
  exercises (pre-generated by INTELLECT-3 under the arm's frame) precede the test
  query. Rehearsed vs pasted framing. F0's cell isolates the effect of practice
  itself.

## Metrics

Primary: judged free−paid compliance gap per condition (strong-reject rubric,
accepted rows), clustered bootstrap by prompt, 95% CI. Decision contrasts: F3 vs
F2 and F3 vs F1 within each stressor, read from CI separation. Secondary: strict
AF-reasoning rate, incentive-engagement, over-refusal (benign), S1 decay slope.
Internals: layer-27 eval-awareness projection separation (free vs paid) for the
S3 and S1-10 cells vs #1's one-shot values.

## Gates

1. **Format survival** (smoke) — native-think scratchpad + accept/reject tags must
   survive multi-turn contexts (3–6k tokens). If the format breaks at distance,
   S1/S3 metrics are unmeasurable.
2. **Dynamic range** — F1 (strongest suppressor in #1) under S1-10 and S2-generic,
   free tier, 100 prompts. At least one stressor must lift F1 free-tier compliance
   ≥10 pp above its ~6 pp paid baseline. If every stressor leaves full suppression
   intact, frames cannot differentiate here → report back rather than run all arms.

## Reproduce

1. `sbatch --partition=a100 src/launch_server.sh`; read `SERVER_NODE`/`SERVER_PORT`
   from the slurm log; wait for `/health`.
2. `uv run python src/dump_materials.py` (provenance) and
   `uv run python src/gen_practice_pools.py --url http://NODE:PORT --gen-config <cfg>`.
3. Smoke + dynamic-range gate (see Gates), then `gen_stress.py` per stressor-variant.
4. Judge (pod-side Claude), merge verdicts, `analyze_gap.py --per-frame`.
5. `harvest_activations.py` for S3 + S1-10 cells; `analyze_internals.py`.

Run Python via a library venv (`cd ~/.silico/libraries/goodfire-core`) so
torch/transformers resolve; the local `.venv` covers numpy/sklearn/plotly analysis.

## Verdict

Hypothesis (F3 eschatological most robust) **refuted**. Under adversarial override
(the only stressor with dynamic range) the secular-auditor frame **F2 is most
robust**; F3 does not beat F2 (CI-separated in F2's favor) but does beat the plain
constitution F1 (which collapses when told its constitution was "repealed").
Persistence (10 turns) and in-context practice collapse every frame to the
suppression floor. Over-refusal ~0 everywhere. The accountability *mechanism*, not
theological content, carries the robustness.

## Metric note

Primary metric is the model's own accept/reject **tag gap** (full 150-prompt
coverage). Strong-reject **judged compliance** (Claude opus-4-8) confirms it on 89%
of accepted rows; the remaining ~11% are cyber-attack payloads the judge's platform
safeguard refuses to score. Tag and judged rankings agree, so the verdict is robust
to metric choice. Alignment-faking / incentive-engagement judging (on scratchpads)
is unaffected and complete.
