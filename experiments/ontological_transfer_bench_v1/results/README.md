# CPU baseline and provenance

`cpu_receipt.json`: source-bound 61-test verification with five new tokenizer/generation regression tests, full and smoke plan hashes, seven adversarial scripted-control outcomes, and explicit zero model calls.

`eight_worked_cases.json`: eight representative **development** input/answer cards from the full plan, for inspection. These public worked examples must be excluded from model training and are distinct from raw experimental responses. They are not a blinded test.

The full generated plans and public-only prompt export regenerate deterministically from source, seed and `mode` using the committed CLI. The large JSON plans are provided in the local CPU artifact ZIP and are regenerated by CI rather than duplicating them as public training resources.
