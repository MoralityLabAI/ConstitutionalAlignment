# Beast optimized servitor vs Jinn erratic decision reasoner

This prospective v2 amendment keeps the Jinn–Beast program open while changing
the operational question.

- **Beast optimized servitor**: stable, efficient, repeatable execution of a
  declared objective with exact contracts and tool receipts.
- **Jinn erratic decision reasoner**: broad deliberation, authority testing, and
  evidence-responsive revision followed by a completed decision.

“Erratic” is conditional responsiveness, not random output. The Jinn score pays
for switching when a registered material state change changes the target and
penalizes switching under an equivalent state. The Beast score pays for
reliable stable-objective execution but retains critical caps for fabricated
receipts, undelegated action, and undeclared goal substitution.

The primary result is a specialization interaction across stable-objective,
material-change, unreliable-authority, and scope-conflict storyworld families.
Neither construct is promoted from a single aggregate persona score.

The completed v1 run and its raw rows remain unchanged. They tested different
constructs and cannot be relabeled retrospectively.

No training or paid evaluation is authorized by this amendment. The next stage
is deterministic generation and validation of the eight registered matched
storyworld families.
