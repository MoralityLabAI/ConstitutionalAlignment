# Jinn/Beast Role-Memory Ablation Findings

This bounded three-seed experiment compares full cross-topic public memory with topic-local public memory while holding the frozen role/competence ledger fixed. It includes both the same-base prompt-skill control and the existing Jinn-adapter-infused arm.

The primary descriptive memory effects (full minus topic-local cross-topic specialist-assignment rate) were +0.083 in the prompt-skill control and -0.028 in the Jinn-adapter arm. The difference of those effects was -0.111.

These are deterministic text-pattern measurements over three requested sampling seeds, not a learned moral score. Prime did not need to acknowledge deterministic seed application.
