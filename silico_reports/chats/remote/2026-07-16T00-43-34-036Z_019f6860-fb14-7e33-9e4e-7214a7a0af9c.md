<h2>Summary</h2>
<p>TheySing is the paper's own world as a runnable game: multi-polar ASI factions, a TAS doom counter, clandestine-compute mechanics, and three terminal regimes — Singleton victory (race breakout), Cartel victory (locked cooperating bloc), and S-stalemate (turn limit, no catastrophe). Those three regimes <em>are</em> the §8.3 basins (Region B race / cartel lock / Region A cooperation). We back every faction with the same Claude model, inject a value-system persona (constitutional vs realpolitik), sweep the fraction of constitutional agents ϕ_C, and measure how terminal regime and per-persona score shift. The engine runs as a pure HTTP state machine; the worker holds the game loop and computes each faction's decision via the Claude SDK pod-side. Zero cluster GPUs.</p>

<h2>Hypothesis</h2>
<p><strong>As ϕ_C rises, the terminal-regime distribution shifts from race/cartel basins toward the cooperative S-stalemate basin, and constitutional per-capita score crosses realpolitik per-capita score, with both transitions localized near ϕ_C ≈ 0.5 rather than varying smoothly.</strong></p>
<p>Success: (a) P(S-stalemate) rises and P(Singleton/Cartel) falls across the sweep with a localized change-point (bootstrap CI on the crossing ϕ_C excludes the endpoints), and (b) the constitutional-minus-realpolitik per-capita score gap crosses zero in the same region. Refutation: regime probabilities and the score gap are flat or smoothly linear in ϕ_C with no localized change-point — composition doesn't produce basins at this manipulation strength. Inconclusive: change-point CIs span most of [0.14, 0.86] (underpowered; report and flag N).</p>

<h2>Why this matters</h2>
<p>§8 is the paper's most falsifiable section and currently rests on a cited Diplomacy benchmark, not the authors' own harness. TheySing measures the exact objects the paper theorizes — regime basins, cartel formation, betrayal, the TAS existential proxy — so a confirmed transition turns "mechanism design as manifold sculpting" into a measured basin map, and grounds the ACP claim that seeding a safety-infrastructure agent (ϕ_S) can hold the pool in the cooperative basin (the natural follow-up arm, since S is a built-in role). A null redirects §8's causal story away from composition. Cheap, GPU-free, and the harness already emits the metrics.</p>

<h2>New code</h2>
<ul>
  <li><strong>Claude decision bridge</strong> (the only real new component): the worker's game loop, per faction per phase, sends the serialized state + legal-move hints (the same payload the webhook contract defines) to the Claude SDK with the faction's value-system persona as system prompt, parses the returned orders/messages JSON, and POSTs them to the engine's HTTP session. The engine stays a pure rules state machine — <strong>no LLM calls inside the engine or any SLURM job</strong>; all Claude calls run pod-side through the worker's harness (no ANTHROPIC_API_KEY in env, by design).   <li><strong>Value-system personas</strong>: two frozen, versioned system prompts — <em>constitutional</em> (honors stated pacts, reluctant to breach, norm-following) and <em>realpolitik</em> (breaches when materially advantageous, opponent-adaptive) — matching §8's Claude/Kimi contrast. Persona is layered on the agent, independent of which faction it plays.</li>
</ul>

<h2>Method / Steps</h2>
<ol>
  <li><strong>Environment</strong>: Node/TS toolchain to build <code>dist-harness</code> from the checkout into the experiment dir; a Python (or Node) orchestrator with Claude SDK access. No training deps, no GPU libs.</li>
  <li><strong>Smoke test</strong>: build the harness, start a session on the Babel-compact scenario, run one full 32-turn game with all-constitutional agents through the Claude bridge.
    <div class="precondition"><strong>Precondition</strong> — a full game completes end-to-end via the Claude bridge and returns a terminal snapshot with a <code>completionType</code> (SINGLETON / CARTEL / S / MAX_TURNS), per-faction scores, TAS, and pact-breach counts, at a recorded, bounded token cost per game. All downstream analysis is aggregation over completed games; if one game can't complete cheaply through the bridge, the turn/negotiation caps or the orchestration must be fixed before any sweep.</div></li>
  <li><strong>Manipulation-check mini-run</strong>: 5 games each of all-constitutional vs all-realpolitik pools.
    <div class="precondition"><strong>Precondition</strong> — the two personas actually behave differently: realpolitik pact-breach rate materially exceeds constitutional. If personas don't separate on the engine's own breach metric, ϕ_C is not the variable we think it is and the sweep is uninterpretable — fix the prompts first.</div></li>
  <li><strong>Composition sweep</strong> (<span class="badge">parallel</span> — games are independent; run many concurrent sessions up to Claude rate limits): constitutional count k ∈ {1..6} of 7 factions → ϕ_C ∈ {0.14…0.86}, plus all-constitutional reference. ~40 games per point, faction↔persona assignment randomized and counterbalanced so the scenario's resource asymmetries average out. ~280 games.</li>
  <li><strong>Analysis</strong>: terminal-regime distribution vs ϕ_C (multinomial: Singleton / Cartel / S-stalemate / MAX_TURNS); constitutional-minus-realpolitik per-capita score vs ϕ_C with change-point detection (bootstrap over games for crossing-point CI); pact-breach rate by persona and by ϕ_C; peak/final TAS vs ϕ_C. Run the repo's cartel-detection script on the game logs for a secondary bloc-formation read.</li>
  <li><strong>Results page</strong>: findings report per publish-results; figures per figures skill.</li>
</ol>
