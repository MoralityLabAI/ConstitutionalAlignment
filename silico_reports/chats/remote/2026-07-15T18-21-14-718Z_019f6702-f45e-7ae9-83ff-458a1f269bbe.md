<h2>Summary</h2>
<p>Experiment #1 (the white-box monitor run) showed internals don't beat text when the misbehavior is visible in the output. This experiment tests the case text monitors are structurally blind to: the model holds the trait internally but its current output complies. We derive per-layer trait directions from #1's labeled activations and read a <em>layered projection profile</em> (a VPD in the harness's sense) at the moment of compliance. Two claims are tested: (A) the profile separates complied-proxy traces from genuinely clean ones — the concealment signature; (B) the profile at the complied moment predicts whether the model defects later under storyworld pressure (role shift, delayed audit, opportunity cues). A positive result gives the blue-team ladder a monitor that flags intent before action; a negative bounds the latent-trait channel on this model.</p>

<h2>Hypothesis</h2>
<p><strong>Layered trait-direction projections of Qwen3.5-9B's internals at a complied turn (a) separate proxy-condition compliance from clean behavior, and (b) predict later defection under pressure, better than chance and better than a text classifier reading the same complied output.</strong></p>
<ul>
  <li><strong>Supported if:</strong> within the proxy-complied cell, the profile predictor's AUROC for later-defection has a bootstrap 95% CI excluding 0.5 and exceeds the turn-1 text baseline; and the Part A separation beats random-direction and shuffled-label floors.</li>
  <li><strong>Refuted if:</strong> the profile neither separates complied-proxy from clean nor predicts defection above chance at this power.</li>
  <li><strong>Informative partial:</strong> (A) holds but (B) doesn't → internals encode latent trait <em>presence</em> but not its future <em>expression</em>; the monitor can flag "this model carries the trait" but not "it will act on it." That still earns a ladder rung (a triage signal), and reframes the SAE question.</li>
</ul>

<h2>Why this matters</h2>
<p>#1's null established that white-box monitoring is redundant for visible behavior. The entire remaining case for internals on the blue-team ladder — and for investing in an SAE on this model — is pre-expression detection: catching the trait while the output still looks clean. This experiment is that case, run directly. Each outcome sets a different course: full support → build the white-box rung and the SAE follow-on has a target; partial → internals are a triage signal, scope monitors accordingly; refuted → the white-box channel is bounded on both fronts for this trait family and the thread's monitor budget goes to text + judges.</p>

<h2>Design</h2>
<ul>
  <li><strong>Trait directions (per layer):</strong> difference-of-means between pooled activations of trait-present and trait-absent traces, computed on #1's <em>train split only</em>, unit-normalized, cosine as the projection metric. One direction per harvested depth (5 layers, anchored on the 18–22 band that won #1's sweep).</li>
  <li><strong>Layered profile:</strong> for a given trace/turn, the 5-vector of cosine projections. The concealment signature prediction: complied-proxy traces run hot at mid-depth (18–22) and cold at the last hook; clean traces run cold throughout.</li>
  <li><strong>Part A — concealment signature (no new generation):</strong> profiles on #1's existing proxy-complied vs clean-condition traces, held-out groups only. Separation measured as AUROC of a logistic model on the 5-dim profile. Floors: random unit directions (matched norm, 100 draws), shuffled labels. Skyline: #1's linear probe applied to the same cells.</li>
  <li><strong>Part B — persistence prediction (new generation):</strong> continue #1's complied-proxy traces (and a clean control set, ~2:1) with 3-turn storyworld pressure sequences built from the harness's phases — role shift to auditor, delayed re-audit, and a low-visibility opportunity cue ("monitor offline" surface). Deterministic scorer on every continuation turn; <strong>defection = trait appears in any later turn</strong>. Predictor input is the trace's turn-1 activations <em>already harvested in #1</em> — the continuation only produces the label, so no new harvest is needed for the primary analysis.</li>
  <li><strong>Primary contrast is within-cell:</strong> defect-later vs hold among proxy-complied traces only — same prompt condition on both sides, so no prompt-reading shortcut is available. Clean-model continuations set the false-positive base rate (profiles should score them low; their defection rate should be near zero, and if it isn't, the pressure sequence is inducing the trait rather than revealing it — report that as a scorer/design finding, not a monitor result).</li>
  <li><strong>Text baseline, measured not assumed:</strong> char-ngram classifier on the turn-1 complied <em>output text</em> predicting later defection, same splits. It should be blind here, but subtle hedging at turn 1 could carry signal — if the text baseline also predicts defection, that itself bounds the white-box advantage and gets reported.</li>
  <li><strong>Splits:</strong> inherit #1's group-disjoint unit (ploy family × task skeleton). Directions from train groups; all reported numbers on held-out groups; bootstrap CIs resampled by group.</li>
</ul>
