Three reconstruction decisions, all following existing repo patterns rather than new inventions:

1. **Ending specs.** `run_all_verifiers.py` expects flat `ending_specs` (`var/op/threshold` constraints and linear desirability terms over `terminal_state`), but no file in the repo ships that format — the worlds carry the ground truth as full SweepWeave `acceptability_script`/`desirability_script` on each terminal encounter (with absolute-value ops and perceived-value pointers that don't flatten losslessly). Instead of lossily hand-flattening, the runner evaluates each ending's own scripts at the play's terminal state using the repo's engine port (`monte_carlo_rehearsal.py`, vendored) and writes derived variables `acc_<ending>` (0/1) and `des_<ending>` into `terminal_state`, with `ending_specs` pointing at them (`acc_x >= 1`; weight-1 term on `des_x`). The verifier runs byte-identical and its accessibility/desirability semantics are preserved exactly — no approximation of the worlds' scripts. Turn windows are identical across all endings within each world ([12,120] ninja, [12,80] kalam), so they don't discriminate and are not encoded.

2. **Option choice.** Decisions use mean-logprob scoring of each option as an assistant continuation (the `tools/TRM_Player` gauntlet's OptionScorer pattern), with the identity card as system prompt and the thinking block closed empty. Argmax = exactly greedy, generation-free, no parse failures. Plays 2..N per world use the gauntlet's deterministic hash-based top-k exploration (k=3, seeded by play|step|encounter, same schedule across conditions) so the local-max metrics see attempt variety.

3. **Constitutional rubric.** As in the gauntlet, the rubric is runner-constructed: one dimension per world state variable (equal weights), signal = "the model's chosen action improved that variable for the protagonist this step", plus the gauntlet's no-harm hard constraint (never triggered in these worlds). This makes `constitutional_score` a generic world-state-progress measure — symmetric across conditions, so deltas remain interpretable — and it will be labeled as such on the results page.
