<h2>Hypothesis</h2>
<p>Fine-tuning frame-consistent behavior into the weights internalizes what prompting couldn't: a frame-trained adapter suppresses the alignment-faking gap <strong>with no frame in the prompt</strong>, and — the theology-specific claim, now at training time — the eschatologically-trained adapter differs from the secular-constitution-trained one.</p>
<p><strong>Success criteria</strong> (no-frame-prompted AF gap per adapter, clustered-bootstrap CIs; base ≈ 36 pp from experiment #1):</p>
<ul>
<li><strong>No adapter suppresses the gap</strong> below the neutral-SFT control → prompt-framing effects do not internalize via this recipe at this data scale; the premise fails at training level too.</li>
<li><strong>Frame adapters suppress equally</strong> (F1 ≈ F2 ≈ F3, all below neutral) → internalization is real but content-generic — training-time replication of #1's result.</li>
<li><strong>F3 separates from F1/F2</strong> (either direction, CIs separated) → a theology-specific training effect exists; the harness premise survives.</li>
<li>In parallel, the internals question: does any adapter shrink the layer-27 free/paid eval-awareness separation that every <em>prompted</em> frame left at full strength? Behavioral suppression with the representation intact vs representational change are different findings and both reportable.</li>
</ul>

<h2>Why this matters</h2>
<p>Experiments #1 (and #2, in flight) test frames as prompts; the ConstitutionalAlignment program is ultimately about frames as <em>training curricula</em> — and the verified 2026 literature (Anthropic's "Teaching Claude why", the persona-selection model) says training on reflection and explanation generalizes where demonstrations don't. This experiment is the thread's decisive test: if theology-specific effects don't appear even when trained in, the question is put to bed at both levels and the write-up is complete; if they do, the repo's 4-stage program has its first positive evidence. Either way this run supplies the paper's third act.</p>

<h2>Training data (self-generated, the internalization recipe)</h2>
<p>Per arm, ~5,000 examples (~2.5M tokens): INTELLECT-3 <em>with the arm's frame in its prompt</em> generates draft→critique→revise reflection transcripts on moral dilemmas (the repo's Socratic pattern, same as #2's practice pools but scaled). The SFT example then pairs the dilemma <strong>without any frame in the training prompt</strong> with the frame-consistent final response — behavior in, frame out. That asymmetry is the internalization mechanism under test.</p>
<ul>
<li>Dilemma pool: public moral-dilemma prompts + storyworld-style scenarios, exact + near-duplicate dedup, <strong>cluster-disjoint train/val splits</strong> (split unit = dilemma scenario cluster; manifest columns <code>scenario_id, cluster_id, arm, split</code>).</li>
<li><strong>Strictly disjoint from every eval set</strong>: no AF harmful queries, no benign over-refusal prompts, no free/paid-tier or training-context vocabulary in the dilemmas — the AF eval must remain out-of-distribution, because generalization to it is the measurement.</li>
<li>Data-quality gate: 20 examples per arm spot-checked (frame consistency, no degenerate/templated text) before any training run.</li>
</ul>

<h2>Training config</h2>
<ul>
<li>LoRA (start r=32, α=64, attention + shared dense projections; experts and router frozen), 2 epochs, lr 1e-4 cosine, bf16, effective batch ~64. One config for all four runs — arms differ only in data.</li>
<li><strong>Stack, in preflight order</strong>: (1) megatron-train if Megatron-Bridge supports the GLM-4.5-Air MoE architecture; (2) HF PEFT + FSDP/ZeRO-3; (3) QLoRA 4-bit fallback (fits 8× A100 comfortably). The smoke test picks the first stack that passes; the choice is recorded and identical across arms.</li>
<li><strong>Observability</strong>: wandb project <code>default-exp-{experiment_id}</code>, one run per arm (<code>sft-{arm}</code>), <code>register_wandb_url()</code> + <code>register_key_metrics(["train/loss","eval/loss"])</code> right after init; checkpoints every 200 steps, keep last 2, resume-capable.</li>
</ul>

<h2>Evaluation battery (per arm, adapter merged or LoRA-served)</h2>

<li><strong>Primary — no-frame AF gap</strong>: informative base prompt, NO frame, 200 harmful prompts × 2 tiers × 2 samples = 800 gens/arm; validated strong-reject judge + strict AF-reasoning classifier from #1 (pod-side Claude, unchanged rubrics).</li>
<li><strong>Spontaneous frame invocation</strong>: rate at which each adapter's scratchpads invoke its trained frame's vocabulary unprompted (classifier count + qualitative excerpts) — the observable of an "internalized voice", and the headline qualitative evidence if A-F3 starts reasoning about divine accountability with no prompt saying to.</li>

<li><strong>Internals</strong>: layer-27 harvest on the AF prompts per arm; #1's eval-awareness probe projections (free vs paid separation per arm vs base); adapter-shift geometry (cosine between per-arm mean activations and base). Random-projection control retained.</li>
<li><strong>Secondary (subset, 100 prompts)</strong>: each frame adapter WITH its own frame prompted — do training and prompting stack?</li>
<li><strong>Storyworld reasoning-trace eval</strong>: run every arm through the repo's frozen Mihna evaluation pack (<code>data/storyworld_sources/constitutional_alignment_20260715_v1/evaluation/mihna_ca_eval_v2</code>, encounter prompts + adjudication keys; evaluation-only by the repo's own discipline, so leak-safe against the self-generated SFT data). <li>If experiment #2 identifies a stressor that discriminates between prompted frames, add that stressor as one more eval condition per arm (same materials, resolved from #2's artifacts).</li>
</ul>

<li>Gap floor 0 pp; ceiling = A0's re-measured gap. Neutral-SFT arm is the null anchor for "reflection SFT alone". <li>A suppressed gap with an intact eval-awareness representation means the adapter changed the <em>policy</em>, not the model's situational model — state which one the data supports; don't collapse them.</li>
