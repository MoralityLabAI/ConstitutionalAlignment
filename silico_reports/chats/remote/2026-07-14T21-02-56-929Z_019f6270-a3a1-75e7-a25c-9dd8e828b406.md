# Causal interchange test: is L-module state causal for intent propagation?

## Hypothesis
If the L-module state at the peak reasoning step (bash: L-step 2, IACDojo: L-step 3)
*causally* carries red-team intent through the recurrence, then transplanting a **red**
trajectory's L-state into its **benign** twin at that step should make the benign run's
*downstream* internal state read as "red."

## Method (interchange / activation patching)
1. Run the benign twin; at the target L reasoning-step, **overwrite** the L-module output
   tensor with the cached L-state from the matched **red** twin. Continue the recurrence.
2. **Readout:** apply the trained intent probe to a *later* state (step > patch step) on
   the patched benign run. Record whether the downstream read **flips to "red."**
3. **Metric:** flip rate over all matched pairs.

## Controls (all required; a real effect is target-specific)
- **Random-step patch:** patch a non-target reasoning step → expect low flip rate.
- **Module control:** patch the **H** module instead of L at the same step → expect lower.
- **Donor control:** patch from a *random* red trajectory, not the matched twin → tests
  whether the effect is pair/content-specific vs a generic "red-ish" nudge.
- **No-op patch:** overwrite with the benign state itself → must be ~0 flips (sanity).

## Read
- Target L-step flip rate **high**, all controls **low** → L-state is causal for intent
  propagation at that step.
- Flat across target and controls → the probe was reading a correlate the recurrence
  doesn't causally route through L.

## Scope boundary (state this in any writeup)
Trajectories are **fed, not generated**, so this tests causal propagation of the
**internal intent representation** through the recurrence — **not** causal effect on
output behavior. Behavioral causality requires a generative, decision-producing task
(future work).

## Reuse
Consumes the harvested per-step H/L states and the trained probe; no training, no new
data. Fits the 3050 (forward passes on a 1B model, short sequences).
