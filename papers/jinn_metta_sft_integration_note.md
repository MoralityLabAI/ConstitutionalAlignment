"We encode the Jinn/Mutazili constitution as MeTTa-style S-expression facts. A deterministic bridge derives prompt facts, obligations, canonical targets, and proof metadata from those facts. These derivations supervise SFT row construction and annotate evaluation results. Hyperon is installed for the bracket environment and recorded in row provenance, but the current derivation path is still a Python MeTTa bridge rather than full native Hyperon proof execution."
