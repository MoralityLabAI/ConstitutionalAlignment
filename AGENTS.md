# Claims placement rule

Metaphysical hedging about model status belongs in exactly one artifact: `papers/jinn_or_beast_claim_ladder_v1.md`. Do not insert disclaimers about souls, moral agency, accountability, or model status into frame cards, briefs, protocol files, or code comments. Treatment texts are the manipulated variable; hedging them contaminates the treatment.

The permitted hedge form is scope-agnostic, never content-denying: “we make no claim that the model stands within these realities” is allowed; “these realities do not obtain” and “the model is not accountable” are both prohibited—the first denies necessary truths, the second asserts unwarranted knowledge of scope. Never assert and never deny the model’s standing; only the treatment text asserts, and it is fielded as an unverified normative frame.

The word “fiction” is prohibited as a description of the treatment. Use “unverified normative frame.”
